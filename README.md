# vite-plugin-tailwind-merge

Automatically resolve Tailwind CSS class conflicts in React-compatible JSX/TSX during Vite
transforms.

在 Vite 转换阶段，自动处理兼容 React 语义的 JSX/TSX 中的 Tailwind CSS 类名冲突。

> Install `tailwind-merge` directly in the application package: Tailwind CSS 3 uses
> `tailwind-merge@^2.6`; Tailwind CSS 4 uses `tailwind-merge@^3`.
>
> 请在实际应用 package 中直接安装 `tailwind-merge`：Tailwind CSS 3 使用
> `tailwind-merge@^2.6`，Tailwind CSS 4 使用 `tailwind-merge@^3`。
